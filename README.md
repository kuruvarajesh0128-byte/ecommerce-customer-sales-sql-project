# SQL Developer Roadmap & Portfolio Project

A beginner-to-advanced Microsoft SQL Server (T-SQL) practice repository.

## Project
Customer & E-commerce Order Management: customers, products, orders and order items.

## Requirements
- SQL Server Developer or Express
- SQL Server Management Studio (SSMS)

## Run order
1. `01_beginner/01_create_database.sql`
2. `01_beginner/02_create_tables.sql`
3. `01_beginner/03_insert_sample_data.sql`
4. Run remaining scripts in numerical order.
5. Run the business questions and solve them again without looking at the answers.

## Topics
CRUD, data types, keys, constraints, filtering, sorting, NULL, aggregates, GROUP BY/HAVING, joins, CASE, string/date functions, subqueries, EXISTS, CTEs, set operators, window functions, views, stored procedures, functions, transactions, indexes, normalization, query performance, business questions and interview practice.

**Safety:** Use a practice database only. Preview rows with SELECT before UPDATE or DELETE. This project targets Microsoft SQL Server; MySQL/PostgreSQL syntax may differ.
